## 4. Security assessment of the two fixes

- **FIX-1 `known_refs` oracle** (`pack_assembler.py:57-80`): `if known_refs is not None and r not in known_refs: return
  False`. The allowlist is a set/frozenset of governance refs (`ev::{category}::{key}`) — **no PII, no secret**. It is
  **owner-populated at the integration step** (M6-OD-013 forward), so today it is a proven mechanism, not a live
  authenticity guarantee (the default no-allowlist path keeps the M6.2L slot-correctness bar). No new access surface;
  the assembler has no `app/api` caller (grep-confirmed at the boundary's N5).
- **FIX-2 `_nonblank` / `recorded` / `_smokes`** (`models.py:17-57`, `pack_assembler.py:154-171`): status/correlation/
  evidence validation and whitespace→None normalization. **No PII** — correlation_id/evidence_id are still masked on
  export via `mask()`. Security-**positive**: closes the F-EVID-1 whitespace launder.
