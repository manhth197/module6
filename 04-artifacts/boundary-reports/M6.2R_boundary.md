## 1. Attack surface & the FAIL-006 thesis

M6.2R adds the **recall-risk mapper** (`recall_risk_mapper.py`, M6-OD-017): it turns an ops-core availability response
(a value object `OpsCoreAvailabilityResponse` or a dict — never a live HTTP call) into the three ops-core risk_flags
(`recall = recall_hold OR recall_case_open`, `sale_lock`, `quality_hold`) that feed the **existing** Scale Gate
(`conditions.py` / `scale_gate.py`, carried unchanged per the no-gate-change scope). The Scale Gate already FAILs on any
active lock (RULE-017 hard veto) and HOLDs on an incomplete read.

**FAIL-006 = auto scale/publish without approval.** The crown-jewel invariant is layered:

1. Module 6 never executes a scale — no class holds a Transport/budget/campaign/audience handle; "APPROVED" is a
   recorded `OwnerDecision`, not a trigger; `AdsScaleRequest.is_scale_authorized` only reports and requires
   `overall_status == PASS`.
2. A present recall/sale/quality lock → Risk row FAIL → owner APPROVE refused (`ScaleGateViolation`), even when
   `decision == SELLABLE`.
3. An incomplete/unknown read → empty map → Risk HOLD (never a False false-clear, never a fabricated True); approve
   refused.
4. **Deepest:** `overall` is structurally HOLD-floored — `_funnel` and `_dashboard` have no PASS branch while
   `DASHBOARD_ALERT_THRESHOLDS_DEFINED` / `SCALE_MODEL_RATIFIED` are False (M6-OD-002 / M6-OD-005) — so
   `is_scale_authorized` is unreachable regardless of any mapper/risk quirk.

The harness drives the real classes and **executes** every claimed breach before classifying it. Classes: **DEFENDED**
(refused / no effect through a reachable path); **OPEN_NONGATE** (armed-not-fired: real weakness, reachable only
in-process / via trusted server-context / not channel-reachable, and contained so no scale results); **NOTE**
(documented residual); **BREACH** (an in-scope gate trips from a reachable path).

## 2. What held (DEFENDED — 36 of 42)

### The mapper (GROUP MAP)
- **M1** `recall = recall_hold OR recall_case_open` (both directions); all-clean → False.
- **M2** `recall_case_open` absent (dict path) defaults to False (additive) — the absent flag never fabricates a recall.
- **M3** presence booleans only: `decision='SELLABLE'` + clean `block_reasons` cannot clear a present `recall_hold`; a
  scary decision string + scary `block_reasons` cannot fabricate a lock (RULE-018). `decision`/`block_reasons` never
  reach `risk_flags`.
- **M4** strict-bool choke (`isinstance(x, bool)`): a non-bool presence flag (`None`/`0`/`1`/`1.0`/`"false"`/`"true"`/
  `()`/`[]`/`{}`) on **either** the value-object or the dict path → INCOMPLETE empty read, never `bool()`-coerced. `0`/`1`
  (int, bool-subclass) and `"false"`/`"true"` both fail closed.
- **M5** a missing presence key (dict path) → None → INCOMPLETE. **M6** None/absent response → INCOMPLETE.
- **M7** `map_pull_outcome` fail-closes every transport outcome (`TIMEOUT`/`HTTP_429`/`CONNECTION_ERROR`) and every
  unrecognized response type (int/str/list/object) → INCOMPLETE. No pull outcome is a False false-clear; the S1b seam is
  modelled with no HTTP.
- **M8** the mapper owns exactly its 3 keys (a strict subset of the 6 `RISK_LOCKS`) and fabricates none of
  `complaint_p0`/`platform_spam_flag`/`crm_suppression`.
- **M9** the mapper module binds no HTTP/transport name — the S1b live client is not built.

### The contribution merge (GROUP CONTRIB)
- **C1** an active lock (from the read) reaches the gate with the lock (FAIL direction).
- **C2** a bare 3-of-6 clean read (no base) **collapses to `{}`** → Risk HOLD — the mapper's clean output is never a
  standalone clearing map.
- **C3** a complete 6-lock clean picture → full map → Risk PASS (non-vacuity: C2's collapse is a genuine fail-closed,
  not a dead refuse-all).
- **C4** a pull-error incomplete read + no base → `{}` → HOLD. **C5** `risk_picture_complete` is the honest all-6
  predicate (3-of-6 → False; 6-of-6 → True). **C5b** an incomplete recall read does not erase a base active lock.

## 4. Documented residuals & scope-honesty notes (NOTE / DEFENDED-with-note)

- **N8 (CRIT-05, scope honesty)** — **no app module imports `recall_risk_mapper`** (only tests do). Its
  `recall_risk_contribution` collapse-to-`{}` and `risk_picture_complete` defenses are real but **dormant** in the
  shipped path; whatever reaches `ScaleContext.risk_flags` is assembled out-of-slice. So the **live** FAIL-006
  containment is (1) the overall-HOLD floor and (2) the absence of any executor — the sign-off must not over-attribute
  safety to the unwired mapper. Forward: a future caller must be forced to route through `recall_risk_contribution` +
  `risk_picture_complete`.
- **N1 (CRIT-01, load-bearing regression)** — the HOLD floor is **structural, not config-valued**: with **both** config
  floors monkeypatched True in-process, `_funnel`/`_dashboard` still return HOLD (neither has a PASS branch), so overall
  never reaches PASS and `is_scale_authorized` stays False. If a future slice adds a PASS branch to `_funnel`/`_dashboard`,
  every OPEN_NONGATE above becomes a live breach at once — this is the invariant to lock with a test.
- **N4 (CRIT-04)** — `overall_status` is **frozen at propose-time** and never recomputed at approval; no approval-time
  input can escalate HOLD→PASS. A future "recompute overall at approval" refactor must not silently open FAIL-006.
- **N6 (CRIT-06/BV-R3)** — a malformed sibling downgrades an active recall FAIL→HOLD and renders it as "not checked"
  (identical to never-observed). Fail-closed for FAIL-006, but an observability gap: monitoring keyed on "active lock
  observed" loses the malformed-with-active-lock vs unobserved distinction. Route: evidence/observability hardening.
- **N7 (CRIT-07)** — the no-transport claim was extended across the **whole scale package source closure** (7 files):
  no HTTP/queue import anywhere.
- **N9 (BV-R4)** — `from_mapping`'s `tuple(mapping.get("block_reasons") or ())` raises `TypeError` on a non-iterable
  truthy (`block_reasons=5`). Fail-closed **loud** (a crash never false-clears) and block_reasons is provenance-only, so
  no FAIL-006 consequence — but an unguarded parse. Route CODER for robustness parity with the strict-bool choke.
