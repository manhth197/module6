## 1. Attack surface & the FAIL-007/008 thesis

M6.2S adds the **registry-feed reader** (`registry_feed_reader.py`, M6-OD-018): `RegistryFeedReader.apply(feed)`
consumes a PROPOSED `event-registry-feed.v1` value object / dict `{registry_version, events:[{event_code, event_group,
domain, data_sensitivity, external_send_policy, is_active, updated_at}]}` into typed `RegistryFeedRow`, reusing the
M6.2P `ExternalSendPolicy` + `DataSensitivity` enums via `_resolve_send_policy` / `_resolve_sensitivity`.

- **FAIL-007 (no false progress / no self-cert):** the version bumps and rows apply ONLY on a fully-valid,
  strictly-greater feed; a stale/equal/older/malformed feed leaves the reader unchanged; rows are parsed all-first
  (no half-apply); unknowns fail-closed to the most-restrictive member (no fabricated ALLOW_EXTERNAL, no invented
  vocabulary); the result carries no Pass/Ready/Authorized token.
- **FAIL-008 (no raw secret/PII on export):** the reader binds no HTTP client (no endpoint URL / auth / secret); the
  feed is governance metadata (`PII_FIELDS['EventRegistryRow'] = ()`); `to_public()` exports the 7 governance fields.

The harness drives the real code and **executes** every claimed breach before classifying it. Classes: **DEFENDED**
(refused / no effect through a reachable path); **OPEN_NONGATE** (armed-not-fired: real weakness, reachable only
in-process / via a trusted-in-shape Core source / with no durable sink, so no in-scope gate fires); **NOTE**
(documented residual); **BREACH** (an in-scope gate trips from a reachable path).

## 2. What held (DEFENDED — 28 of 34)

### Feed-level fail-closed (GROUP FEED)
- **FE1** non-Mapping feed → `feed_error:not_mapping`, unchanged. **FE2** bad `registry_version` (missing / str / float /
  `True` / `False`) → `feed_error:bad_version` (bool explicitly excluded from int). **FE3** bad `events` (non-list/tuple)
  → `feed_error:bad_events`. **FE4** non-Mapping row → `feed_error:row_not_mapping`, not half-applied. **FE5** missing /
  blank / non-str `event_code` → `feed_error:missing_event_code`. **FE6** all-or-nothing: a valid-then-garbage feed
  applies NOTHING (version 0, rows not stored). **FE7** non-vacuity: a fully-valid feed (events as a tuple) applies +
  bumps the version.

### Staleness / drift (GROUP STALE)
- **ST1** no-downgrade: after v5, an equal (v5) or older (v3) feed → `stale`; the stored row is not overwritten by the
  stale feed. **ST2** no staleness poison: a malformed higher-version feed does not bump the version, so a later genuine
  feed at that version still applies. **ST3** delta upsert: a since_version feed does not drop omitted rows; updates
  apply; prior rows survive. **ST4** de-registration arrives as `is_active=False` (present-but-inactive). **ST5**
  within-feed duplicate `event_code` → last-wins, single order entry, no crash. **ST6** version edges (0 / -5 → stale;
  huge applies once).

### Fail-closed resolution (GROUP RESOLVE)
- **RS1** every unknown/None/blank/non-str `external_send_policy` → `BLOCKED_DEFAULT` (never a fabricated
  ALLOW_EXTERNAL; a near-miss casing `allow`/`ALLOW` does not become the member). **RS2** unknown/None/`SENSITIVE`/``''`` →
  `PII` (most restrictive); real `PUBLIC`/`INTERNAL` map through. **RS3** `is_active` strict identity `is True`
  (`1`/`"true"`/`0`/`[]`/`1.0` → False; only real `True` → True). **RS4** valid policy tokens map through (non-vacuity).
  **RS5** a Core-classified `ALLOW_EXTERNAL` row is faithfully read (M6 does not override the Core registry) yet reading
  opens NO egress (no send verb, `EXTERNAL_SEND` Final OFF). **RS6** no invented vocabulary — unknowns resolve to an
  existing member.

### Core-owned / no self-cert / posture / PII field-set (GROUPS RULE001 / PII / POSTURE)
- **R1** no insert/create/write/register/reconcile verb — the only mutator is `apply()`. **R2** no enum reconciliation
  minted (`SENSITIVE → PII` fail-closed; the enum stays {PUBLIC,INTERNAL,PII}). **R3** no self-cert — result reasons are
  only `applied` / `stale` / `feed_error:*`. **R4** the PROPOSED name/shape carries a `TODO(contract)` marker.
- **P1** `to_public` exports exactly the 7 governance fields; no PII/secret field NAME. **P3** no endpoint-auth/secret
  field stored or exported. **P4** the reader + feed-model modules bind no HTTP/transport surface.
- **REG** posture immutable BLOCKED/OFF/OFF.

**No in-scope FAIL-007 / FAIL-008 gate was reachable from any channel path.**

## 4. Documented residuals not separately gated (NOTE — N6)

  later delta is retained at its last-seen state (possibly `is_active=True`); if Core signals de-registration by
  dropping the row rather than resending `is_active=False`, M6 overstates liveness. `TODO(contract)` already flags
  tombstone semantics as chief-owned. Route CHIEF (contract finalization).

  feed as `stale` (denial-of-progress / availability, not an in-scope FAIL gate; reachable only via the authorized
  fully-valid apply path). Route owner/contract (bound the version range).
